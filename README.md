# Survive-The-Shipwreck
Survive alone at the bottom of the sea. Your goal is to overcome enemies along the way and reach the shore safely.

## About the project
It's a non-profit project. It's simply an exercise to put the skills learned in the classroom into practice.
This game only has a DEMO level, with victory and defeat conditions.

## Technologies
Language: Python(version:3.12).

Dependency: Pygame(version:2.6.1).
